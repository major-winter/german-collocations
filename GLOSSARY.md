# German Collocations

A lookup tool that shows German learners which words go together, with example
sentences from a real corpus.

## Language

**Word class**:
The grammatical category a word is shown under: noun, verb, adjective,
preposition, or other. Each word class except "other" has its own colour on the page.
_Avoid_: section, POS (in UI and design talk), Wortart (except as the UI label)
